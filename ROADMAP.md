# Roadmap: улучшения карты грибных биотопов Швеции

Дата: 31.07.2026.

## Фаза 0 — Критические пробелы (архитектура)

### 0.1 Зафиксировать зависимости Python
- [ ] Создать `pyproject.toml` с зависимостями: `numpy`, `rasterio`, `Pillow`
- [ ] Зафиксировать версии через `uv lock` или `pip freeze > requirements.txt`
- [ ] Добавить `scripts/rebuild.sh` — проверяет наличие venv, устанавливает зависимости, запускает сборку

### 0.2 Единый orchestration сборки
- [ ] Создать `Makefile` с целями:
  - `make sweden` — `scripts/build_sweden_habitat.py`
  - `make varmland` — `scripts/build_varmland_habitat.py`
  - `make all` — обе цели последовательно
  - `make validate` — проверка, что все PNG в assets/ существуют и не пусты
  - `make clean` — удаление сгенерированных PNG
- [ ] Консолидировать константы (bbox, размеры сетки) в общий модуль, если они дублируются

### 0.3 Разделить index.html
- [ ] Вынести данные точек (SPECIES) в отдельный файл `data/species.json` — загружать через `fetch()` при старте
- [ ] Вынести CSS стилей страницы (не Leaflet) в `assets/style.css`
- [ ] Leaflet 1.9.4 и Chart.js 4.4.1 грузить с CDN (`unpkg.com` / `cdnjs`) вместо встроенных копий
  - [ ] Оставить inline-копию как fallback для офлайн-режима (см. Фаза 2)
- [ ] Проверить, что после разделения страница работает от `file://` и от `http://`

### 0.4 Тесты на Python-скрипты
- [ ] Написать smoke-тесты (pytest):
  - `test_sweden_habitat.py` — вызов скрипта на маленьком синтетическом GeoTIFF, проверка метаданных и размеров выходных PNG
  - `test_varmland_habitat.py` — то же для Värmland
  - `test_class_scores.py` — юнит-тесты на `class_score()`, `reduce_max()`, `reduce_coverage()`
- [ ] Добавить `make test` — запуск pytest

### 0.5 ScrollWheelZoom
- [ ] Включить `scrollWheelZoom: true` на карте (или добавить кнопку временного включения)
- [ ] Если опасение за случайный зум при скролле страницы — использовать `scrollWheelZoom: 'center'` (зум под курсором, а не под центром экрана)

## Фаза 1 — FOREST_LAYER_FIX_PLAN.md (следующий уровень точности)

### 1.1 NMD2023 — дополнительные слои пород
- [ ] Скачать NMD2023 дополнительный слой долей пород (NMD2023 trädslag) с Naturvårdsverket
- [ ] Добавить в `build_sweden_habitat.py` второй растр: доли сосны, ели, обычных лиственных, благородных лиственных, отдельно бука и дуба
- [ ] Пересчитать скоринги для каждого вида с учётом долей, а не только категорий basskikt
- [ ] Для чёрной лисички это особенно важно — сейчас noble deciduous (класс 116) даёт 90, но бук и дуб имеют разные веса

### 1.2 Skogsstyrelsen Skogliga grunddata (общешведский)
- [ ] Скачать растры по Швеции: высота, средний диаметр, объём, базальная площадь, влажность почвы (SLU Markfuktighet)
- [ ] Добавить в `build_sweden_habitat.py` как дополнительные признаки
- [ ] Сейчас эти данные есть только для Värmland в `build_varmland_habitat.py`
- [ ] Слой канав и торфа (diken/torf) — для трубковидной лисички

### 1.3 SGU Jordarter — общешведский охват
- [ ] Собрать типы грунтов для всей Швеции через SGU OGC API: `https://api.sgu.se/oppnadata/jordarter25k-100k/ogc/features/v1/`
- [ ] Растрифицировать в общую сетку NMD (2200×6000)
- [ ] Добавить в `build_sweden_habitat.py` как дополнительный признак скоринга
- [ ] Сейчас SGU — только Värmland, подпись в UI говорит «грунт SGU: нет локальных данных» за пределами

### 1.4 Валидация по пространственно разделённой выборке
- [ ] Собрать GBIF-наблюдения с координатами (не только агрегаты)
- [ ] Разделить на train/test по пространству (например, по 10-километровой сетке)
- [ ] Рассчитать precision@k, AUC-ROC пригодности биотопа vs наблюдения
- [ ] Записать результат в `VALIDATION.md`

### 1.5 Рубки и нарушения — улучшить
- [ ] Сейчас WMS-слои живые, это хорошо
- [ ] Предрасчитывать растр «свежие рубки» (Skogsstyrelsen avverkningsanmälan) как предупреждение в клик-попапе
- [ ] Добавить слой «возраст рубки» (год) — если рубка была 5+ лет назад, лес может восстанавливаться

## Фаза 2 — Новые фичи

### 2.1 PWA + Service Worker
- [ ] Создать `manifest.json` с иконками, названием, цветом темы
- [ ] Создать `sw.js`:
  - Кэшировать все растры `assets/habitat-sweden/*.png` и `assets/habitat/*.png` при первом заходе
  - Кэшировать Leaflet + Chart.js из CDN
  - Стратегия: cache-first для растров, network-first для API (GBIF, Open-Meteo, WMS)
- [ ] Подключить в `<head>` index.html
- [ ] Добавить `apple-touch-icon` и мета-теги для iOS

### 2.2 Offline-карта
- [ ] Скачать тайлы OpenStreetMap для Швеции на z6–z10 (~500 МБ) или использовать MBTiles
- [ ] Добавить переключатель «онлайн / офлайн» в слой карты
- [ ] Офлайн-режим: Leaflet TileLayer с локальными тайлами из cache API
- [ ] Для первого релиза — просто fallback: если нет сети, показать сообщение и использовать растры без подложки

### 2.3 GPX-трек экспорта
- [ ] Добавить кнопку «📥 GPX» рядом с координатами
- [ ] Генерировать GPX-файл с waypoint выбранной точки и description из оценки
- [ ] Использовать `data:text/xml;charset=utf-8,` + download attribute
- [ ] Добавить «📥 KML» для Google Earth

### 2.4 Слой пожаров (MSB / Krisinformation)
- [ ] Подключить WMS или GeoJSON с актуальными лесными пожарами от MSB (Myndigheten för samhällsskydd och beredskap)
- [ ] Показывать как отдельный слой в `L.control.layers`
- [ ] Для мацутаке — гарь может быть позитивным сигналом, для лисичек — негативным

### 2.5 Слой осадков за 30 дней
- [ ] Open-Meteo API позволяет `past_days=30` (сейчас 14)
- [ ] Добавить второй график / метрику: осадки 30 дней, глубже 50 мм — риск вымывания
- [ ] Показывать в popup строку «осадки 30 дней: X мм»
- [ ] Сделать тренд: «последние 7 дней vs предыдущие 7» — растёт или падает влажность

### 2.6 Слой высоты / экспозиция склона
- [ ] Open-Meteo API: `elevation` уже приходит бесплатно
- [ ] Добавить в `build_sweden_habitat.py` расчёт экспозиции из SRTM / EU-DEM
- [ ] Для мацутаке: южные склоны теплее, суше — предпочтительны
- [ ] Для чёрной лисички: северные склоны влажнее — предпочтительны
- [ ] Показывать в popup: «высота X м, экспозиция: Ю/С/З/В»

### 2.7 Open Graph / Twitter Card
- [ ] Добавить мета-теги в `<head>`:
  ```html
  <meta property="og:title" content="Грибные биотопы Швеции">
  <meta property="og:description" content="...">
  <meta property="og:image" content="https://.../preview.png">
  <meta property="og:type" content="website">
  ```
- [ ] Сгенерировать preview-изображение 1200×630 (скриншот карты с легендой)
- [ ] Добавить `twitter:card` мета-теги

### 2.8 make rebuild — одна команда
- [ ] `make rebuild` = `make clean && make all && make validate && make test`
- [ ] Добавить `make deploy` — копирование assets/ в директорию для статического хостинга

## Критерий готовности каждой фазы

- Все пункты выполнены
- `make test` проходит
- Страница открывается в Chrome, Firefox, Safari
- Растры пересобраны и имеют корректные размеры и метаданные
- Нет регрессий в существующих функциях (клик, поиск, погода, слои)
