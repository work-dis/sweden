# 🍄 Где растут лисички в Швеции

Интерактивная карта и справочник по сбору лисичек (Cantharellus) в Швеции: конкретные места,
реальная плотность находок из GBIF/Artportalen, сезонность и практический гид.

## Что внутри
- **`kantareller_sverige.html`** — самостоятельная интерактивная страница (карта + графики + гид).
- **`index.html`** — копия страницы для GitHub Pages (точка входа).

## Карта — три слоя
- 📍 **22 конкретных места** (нацпарки, природные резерваты, известные грибные леса) с описанием
- 🔥 **Живой слой плотности находок** из GBIF (16 000+ точек с координатами)
- ⭕ **Суммы по провинциям** (ландскапам)

Есть переключатель между обыкновенной и трубковидной лисичкой.

## Данные и сезон
- 15 715 находок обыкновенной лисички (*C. cibarius*), 10 007 — трубковидной (*C. tubaeformis*)
- Пик сезона — **сентябрь** (август–октябрь), старт с июля
- Юг (Гёталанд) — ~55% всех находок

## Как открыть
Открой `kantareller_sverige.html` в браузере. Для карты и графиков нужен интернет
(подгружаются тайлы карты, слой плотности GBIF и библиотека графиков).

## GitHub Pages
Settings → Pages → ветка `main`. Страница будет доступна по адресу
`https://work-dis.github.io/sweden/`

## Источники
GBIF (Artportalen), Naturvårdsverket (Allemansrätten), Svampindex, Naturhistoriska riksmuseet, SVT.
Числа отражают и обилие грибов, **и активность наблюдателей**.

## Оговорка
Пины — ориентиры по районам с подходящим биотопом, а не «гарантированная точка».
В охраняемых зонах правила сбора различаются — проверяй аншлаги на входе.
