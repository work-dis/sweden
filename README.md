# 🍄 Грибные биотопы Швеции

Самостоятельная интерактивная страница о пяти видах грибов:

- обыкновенная лисичка (*Cantharellus cibarius*);
- трубковидная лисичка (*Craterellus tubaeformis*);
- чёрная лисичка (*Craterellus cornucopioides*);
- королевский мухомор (*Amanita regalis*, ядовит);
- мацутаке / голиаф-муссерон (*Tricholoma matsutake*, VU в Красном списке Швеции 2025).

## Что показывает страница

- тепловой слой наблюдений GBIF/Artportalen;
- переключаемую подложку OpenStreetMap с видимым лесным покровом;
- общешведская серая маска всех распознанных лесов NMD2023 и отдельный цветной
  слой соответствия выбранному виду с управляемым порогом 40/60/75;
- определение текущего местоположения с отображением точности GPS и расчётом
  выбранного лесного участка;
- выбранную точку с копированием координат и ссылками в навигаторы;
- автоматический поиск более подходящего участка в радиусе 3 км;
- две раздельные оценки: постоянная пригодность биотопа и текущие погодные
  условия;
- грунты SGU: песок/гравий, морена, глина/ил, торф и скала;
- высоту места и осадки за 7/14 дней;
- официальные WMS-слои Skogsstyrelsen: заболоченные леса, ключевые биотопы,
  объекты природной ценности, природоохранные договоры, заявки на рубку и
  выполненные рубки;
- дополнительный слой покрова NMD2023;
- отдельные записи наблюдений с точностью координат;
- природные территории с потенциально подходящим лесом;
- сезонность и число записей по историческим ландскапам;
- матрицу «тип леса → какие виды там вероятны».

## Важное различие

Поле `stateProvince` в шведских данных GBIF преимущественно содержит исторические
ландскапы (`landskap`), а не современные административные лены (`län`). В описаниях
точек поле «география» может включать лен, коммуну или ближайший город и не
используется для рейтинга ландскапов.

📍 означает запись наблюдения. Тип леса для такой точки не считается
подтверждённым, если его нет в исходных данных. 🌲 означает кандидатный биотоп:
описание леса территории подходит экологии вида, но это не подтверждённая находка.

## Запуск

Для полноценной работы оценки по клику запустите локальный сервер:

```bash
python3 -m http.server 8765
```

Затем откройте `http://localhost:8765/`. Интернет нужен для тайлов карты,
динамического слоя GBIF, WMS Skogsstyrelsen/NMD и погодных данных Open-Meteo.
Основные библиотеки включены в `index.html`.

## Национальный слой Швеции

Основной слой строится из общешведского NMD2023 basskikt v2.1
Naturvårdsverket. Он классифицирует сосновые, еловые, смешанные хвойные,
смешанные хвойно-лиственные, обычные и благородные лиственные леса, отдельно
на твёрдом и влажном грунте, с исходной ячейкой 10 м.

В браузер передаётся агрегированный растр. Чтобы небольшие и узкие леса реже
исчезали при агрегации, NMD сначала регулярно выборочно читается в сетку
удвоенного разрешения, после чего наличие леса и максимальная пригодность
сохраняются в каждой группе 2 × 2. Фрагментарные ячейки рисуются прозрачнее
сплошных.

Серая маска показывает все распознанные леса, янтарная — лесную землю,
временно оставшуюся без древостоя после рубки/пожара либо с молодняком ниже
порога NMD. Цвет оценивает совместимость класса текущего леса с выбранным видом
гриба по всей Швеции. Национальная оценка не
включает грунт, влажность, непрерывность древостоя, свежие рубки и погоду,
поэтому называется пригодностью **по типу леса**, а не полной пригодностью
биотопа или вероятностью находки.

Исходный GeoTIFF хранится локально в
`data/raw/sweden/NMD2023bas_v2_1.tif` и исключён из Git. Рядом сохранён
официальный архив `NMD2023_basskikt_v2_1.zip`. Пересборка:

```bash
python3 scripts/build_sweden_habitat.py \
  --base-raster data/raw/sweden/NMD2023bas_v2_1.tif \
  --output-dir assets/habitat-sweden
```

Источники: [Naturvårdsverket — NMD и дополнительные слои](https://www.naturvardsverket.se/verktyg-och-tjanster/kartor-och-karttjanster/nationella-marktackedata/ladda-ner-nationella-marktackedata/),
[Skogsstyrelsen — национальные лесные характеристики](https://www.skogsstyrelsen.se/en/digital-open-forest-data/national-forest-attribute-maps/).

## Детальная модель Vålberg–Karlstad

PNG-слои в `assets/habitat/` собраны из открытых растров Skogsstyrelsen/SLU
и полигонов SGU для Värmlands län: объёмы сосны, ели, берёзы, дуба и бука,
средний диаметр, классифицированная влажность и тип грунта. Исходная ячейка
породных данных — 12,5 м.

Локальное число 0–100 — относительная **пригодность лесного биотопа**, а не вероятность
найти плодовое тело и не прогноз урожая. Наблюдения GBIF не входят в формулу.
Цвет не рисуется вне лесной маски (объём древесины, валидный средний диаметр и
класс влажности SLU); значения ниже 40 по умолчанию скрыты как малоинформативные.
Воспроизводимый генератор находится в
`scripts/build_varmland_habitat.py`, параметры и имена входных файлов — в
`assets/habitat/metadata.json`. Погодная оценка рассчитывается в браузере по
осадкам и средней температуре последних 14 дней; она не входит в постоянный
растр пригодности.

Исходные GeoTIFF хранятся локально в `data/raw/varmland/` и исключены из Git.
Они используются для воспроизводимости и локальной детализации грунта:

```bash
python3 scripts/build_varmland_habitat.py \
  --input-dir data/raw/varmland \
  --output-dir assets/habitat \
  --soil-geojson \
    data/raw/varmland/soil/sgu-soil.json \
    data/raw/varmland/soil/sgu-page-10000.json \
    data/raw/varmland/soil/sgu-page-20000.json
```

Без локальных выгрузок SGU в `--soil-geojson` категория грунта будет
неизвестной.
